/ARCHITECTURE /DEVELOPMENT VIEW

The Development View describes how the Intaliq code is organized: components, packages, layers and their dependencies. The SE365 high-fidelity prototype was designed in Figma, built with JavaScript, HTML and CSS using Vite, backed by Supabase, versioned on GitHub and deployed on Vercel. That stack is the starting point for this architecture.
